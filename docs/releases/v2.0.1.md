本次发布包含 2.0.0 的框架迁移和隐私更新。2.0.0 标签未生成 APK。

## 发布修复

- 改用 GitHub Actions 运行器预装的 Android SDK 35 和 Build Tools 35.0.0，修复发布流程在 SDK 准备阶段失败的问题。

## 框架兼容性

- 迁移到现代 Xposed API 101，静态作用域仅限系统框架（system）。需要支持现代 API 101 的框架，例如 Vector 2.2 或更高版本。仍依赖旧版框架的设备请继续使用 1.0.0。
- 覆盖安装签名相同的 APK 后，在框架管理器中确认模块已启用，然后重启设备。系统要求仍为 Android 15 或以上。

## 隐私与清理

- 跳过被来源应用标记为敏感的剪贴板内容；保留系统原有的剪贴板读取提示。
- 停止保存链接与口令的打开记录。覆盖升级后首次启动会删除旧记录，保留现有规则和设置。
- 应用数据不再纳入 Android 云备份和设备迁移。通知正文不显示自定义规则名称，模块诊断只输出固定消息。
- 移除了旧版 Xposed 模块入口和不再使用的打开记录代码。链接、口令匹配及点击通知跳转仍可使用。
